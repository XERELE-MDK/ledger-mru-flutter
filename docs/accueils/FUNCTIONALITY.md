# Écrans d'accueil — fonctionnement

[← Toutes les fonctionnalités](../README.md) · [Parcours du code](CODE_WALKTHROUGH.md)

Paramètres → Écran d'accueil :

| Accueil | Idée |
|---|---|
| **Aperçu** | cartes, catégories, avoirs, dernières écritures |
| **Éditorial** | le mois en une phrase, barre empilée des catégories |
| **Compte en T** | le mois en page débit / crédit, l'écart reporté pour équilibrer |
| **Galets** | dépenses en cercles, rythme jour par jour |

Le choix est propre à chaque appareil.
