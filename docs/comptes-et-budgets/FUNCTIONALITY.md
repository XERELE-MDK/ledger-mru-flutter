[← Toutes les fonctionnalités](../README.md) · [Parcours du code](CODE_WALKTHROUGH.md)

## Ce que ça fait

Cinq types de comptes : **actif** (ce que j'ai), **passif** (ce que je dois), **capitaux propres**, **revenu**, **dépense**. Un compte de dépense peut avoir un **budget mensuel**.

## Règles

- Le nom est obligatoire.
- Un compte utilisé par une écriture ne peut pas être supprimé.
- Changer le type d'un compte utilisé reclasse tout son historique.
