# Sync — setup

[← All features](../README.md) · [How it works](FUNCTIONALITY.md) · [Code walkthrough](CODE_WALKTHROUGH.md)

## 1. Share a folder

Install [Syncthing](https://syncthing.net) on every device and share a folder, for example `~/Sync/Ledger`. Any tool that copies files works.

## 2. The first device

The one with the real data: **Settings → Data & sync → Choose sync folder**.

## 3. The others

Choose the same folder, then:
- **Use folder data** if this device has nothing to keep;
- **Merge** otherwise. Demo data that exists only here is left out.

## Check

Both devices show "Synced at … · 1 other device".

Keep **every** device on the same version.
