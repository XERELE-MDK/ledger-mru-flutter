# Langues — fonctionnement

[← Toutes les fonctionnalités](../README.md) · [Parcours du code](CODE_WALKTHROUGH.md)

La langue est celle de l'appareil si elle est gérée, sinon l'anglais. Elle se change dans Paramètres, sans redémarrer.

Nombres, dates et ponctuation suivent : `1 250,50` · `1,250.50` ; `ven. 20 nov.` · `11月20日(金)`.

Les données (noms de comptes, notes) ne sont pas traduites : ce sont les vôtres.
