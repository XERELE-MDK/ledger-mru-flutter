# Languages — how it works

[← All features](../README.md) · [Code walkthrough](CODE_WALKTHROUGH.md)

| Language | Numbers | Dates |
|---|---|---|
| **English** (default) | `1,250.50` | `Fri, Nov 20` |
| **Français** | `1 250,50` | `ven. 20 nov.` |
| **日本語** | `1,250.50` | `11月20日(金)` |

The language is the device's if it is supported, English otherwise. Change it in Settings → Language, no restart needed. Numbers, dates and punctuation follow.

Your data (account names, notes) is not translated: it is yours. The demo data is created in the device language.

The Rust desktop version is in English only.
