# Synchronisation — mise en place

[← Toutes les fonctionnalités](../README.md) · [Fonctionnement](FUNCTIONALITY.md) · [Parcours du code](CODE_WALKTHROUGH.md)

## 1. Partager un dossier

Installer [Syncthing](https://syncthing.net) sur chaque appareil, et partager un dossier, par exemple `~/Sync/Ledger`. Tout autre outil qui copie des fichiers convient.

## 2. Le premier appareil

Celui qui a les vraies données : **Paramètres → Synchronisation → Choisir le dossier**.

## 3. Les suivants

Choisir le même dossier, puis :
- **Utiliser le dossier** si cet appareil n'a rien à garder ;
- **Fusionner** sinon. La démo présente seulement ici est laissée de côté.

## Vérifier

Les deux appareils affichent « Synchronisé à … · 1 autre appareil ».

Mettre **tous** les appareils à la même version.
